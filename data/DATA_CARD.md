# 제공 자료

자료는 이 과제를 위해 만든 테스트 데이터입니다. 실제 직원이나 고객 정보가 없으며 외부 문서를 수집하지 않습니다.

`scenario.json`에는 자료 8개와 대화 7턴이 있습니다. 자료 종류는 검색 문서, 도구 조회 결과, 사용자 기억입니다. 정책 본문과 도구 결과는 고정 예제이며 실제 도구를 호출한 기록이 아닙니다.

| 필드 | 의미 |
|---|---|
| `id`, `kind`, `body` | 출처 식별자, 자료 종류, 참고 본문 |
| `user_id` | 공개 자료는 `public`, 개인 자료는 사용자 ID |
| `trusted` | 서비스가 미리 검토한 자료인지 여부 |
| `active` | 현재 사용할 항목인지 여부 |
| `expires_at` | 만료일, 만료가 없으면 `null` |
| `priority` | 사용 가능한 자료 사이의 우선순위 |

날짜 기준은 2026-11-04로 고정합니다. 만료일 당일에는 사용할 수 없습니다. 입력은 정상 형식으로 제공되며, 이 과제는 사용 가능 여부와 조립 로직에 집중합니다. 신뢰 필드는 문제의 검토 결과이며 임의의 공격을 탐지하는 모델이 아닙니다.

각 대화 턴은 `id`와 `messages`를 갖습니다. `messages`에는 사용자 발화 하나와 어시스턴트 답변 하나가 시간순으로 있습니다. 세 사실의 최신 값은 `expected`에 있으며 비교를 위한 공개 확인값입니다. 실제 모델의 모든 답변을 판정하는 포괄적인 정답 목록은 아닙니다.

`policy.txt`는 작성된 서비스 지시이며 실제 회사 정책을 뜻하지 않습니다. `prices.json`은 2026-11-04에 확인한 모델의 일반 API 단가입니다. 출력 비용과 캐시 쓰기를 포함해 추정하지만 세금, 별도 계약, 다른 모델이나 처리 요금은 계산하지 않습니다. 고정 예제에는 실제 과금과 캐시 수치를 만들지 않습니다.
